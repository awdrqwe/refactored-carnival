v1.26 (2026-08-03)
- 添加完整的用户权限系统
  - 登录系统：全屏登录遮罩层，SHA-256 密码哈希验证，对接 Supabase profiles 表
  - 三种角色：super_admin（超级管理员）/ editor（编辑者）/ viewer（查看者）
  - viewer：仅可查看和搜索，隐藏所有新增/编辑/删除/锁定/导出/导入按钮，禁用表单输入
  - editor：正常使用停车场数据管理功能，但不能管理用户
  - super_admin：拥有全部权限 + 用户管理面板
  - 用户管理面板：列出所有用户（用户名/角色/创建时间），支持添加用户和删除用户
  - 登录状态持久化到 localStorage，支持登出和重新登录
  - 顶部用户信息栏显示当前用户和角色标签
  - 响应式适配移动端
- Supabase profiles 表：id/username/password_hash/role/created_at，RLS 已禁用
- 默认超级管理员账户：admin/admin123（密码 SHA-256 预置）

v1.25 (2026-08-02)
- 接入 Supabase 云端数据库，实现多设备数据同步
  - 引入 Supabase JS SDK（CDN）
  - loadState() 优先拉取云端数据，云端为空时降级 localStorage
  - saveState() 同步写 localStorage + 1.5 秒防抖推送到云端
  - 首次启动：云端有数据 → 覆盖本地；云端空但本地有 → 推送到云端
  - 停车场的增/删/改自动同步到 Supabase


- 修复 Excel 导入时闸机数量和票机通道数量列索引偏移问题
  - parseExcelToJSON 中 channelCount 从 row[13] 修正为 row[12]（票机通道数量列）
  - gateCount 从 row[14] 修正为 row[13]（车道数量列）
  - v1.23 新增纬度/经度列后，row[14] 被纬度值占用，导致 gateCount 读出纬度数值


- Excel 导出/导入新增地图坐标（纬度/经度列），修复换电脑导入后定位丢失问题
  - 总览 sheet 新增「纬度」「经度」两列（列14/15）
  - parseExcelToJSON 解析时还原 mapCoord
  - smartMergeImport / doImport 新建/合并时携带 mapCoord
